# Arena Launcher

لانشر أندرويد شخصي بطابع رياضي فاخر يجمع الأحمر الداكن مع الأزرق والذهبي، مستوحى من أجواء ليفربول والنصر من دون الاعتماد على صور خلفيات ثابتة داخل الواجهة.

## النسخة 1.0
- شاشة رئيسية، عمل، عائلة، وأنا.
- درج تطبيقات كامل مع البحث.
- اختيار أي تطبيق لكل اختصار بالضغط المطول.
- ثلاثة أنماط: Fusion، Royal Blue، Red Arena.
- الساعة والتاريخ الميلادي والهجري ونسبة البطارية بيانات حقيقية من الهاتف.
- ملاحظات قابلة للتحرير ومحفوظة محليًا.
- يمكن اختياره كتطبيق Home افتراضي.

> بيانات الطقس والصلاة لا تُختلق داخل التطبيق. توجد اختصارات قابلة للربط بتطبيق الطقس أو الصلاة الذي يفضله المستخدم.
